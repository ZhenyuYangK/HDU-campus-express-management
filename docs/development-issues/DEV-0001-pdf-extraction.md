# DEV-0001：MiKTeX版PDF提取工具不可用

- 日期：2026-10-22
- 负责人：初始化执行代理
- 状态：已关闭
- 影响范围：课程资料读取

## 问题场景

读取根目录课程PDF时执行`pdftotext -layout -enc UTF-8 软件工程课程设计PPT.pdf -`，预期得到课件文本，实际退出码为1，报告MiKTeX注册表访问被拒绝，并提示需要完成TeX安装配置。

## 原因分析

本机命中的`pdftotext.exe`属于MiKTeX，其执行依赖MiKTeX初始化及注册表状态。实际日志表明该工具在访问相关注册表项时失败。该失败不能说明PDF损坏。

## 解决方案

改用本机已有的PyMuPDF读取PDF文本并渲染页面。提取时设置Python标准输出为UTF-8，避免中文输出编码错误。没有修改系统注册表，也没有改动原PDF。
