# DEV-0002：本机缺少Docker引擎

- 日期：2026-10-22
- 负责人：初始化执行代理；运行验收由团队后续指派
- 状态：待验证
- 影响范围：镜像构建、容器启动及数据库/文档站点运行验收

## 问题场景

为统一团队环境，需要启动Compose中的MySQL、Swagger UI及开发工具容器。检查本机命令路径及Docker Desktop默认安装位置时，未找到Docker客户端、引擎和Docker Desktop安装文件。

## 原因分析

本机不具备运行容器所需的Docker引擎。单独解析Compose配置不需要引擎，但构建镜像、启动容器及验证数据库连接需要引擎。

## 解决方案

先完成Compose、Dockerfile、环境变量示例与操作文档，并对可执行的部分进行静态校验。不把操作系统级Docker Desktop安装混入目录初始化，不把配置文件存在表述为容器已运行。

在已安装Docker的成员机器执行[开发环境文档](../development-environment.md)中的启动和验证命令，记录真实输出后再决定关闭本问题。
