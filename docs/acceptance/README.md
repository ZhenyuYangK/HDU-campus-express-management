## 系统演示与验证检查

除课程材料外，按仓库开发规范核对以下项目。

- [ ] 以已确认的功能清单逐项演示，实际页面、处理结果和保存后的数据与需求一致；记录演示环境和使用的数据。
- [ ] 接口文档、前端调用、后端实现与数据库设计保持一致，相关变更及验证结果可追踪。
- [ ] 至少两个模块的测试有实际执行结果，能够定位到用例、环境、预期、实际表现和证据；未执行用例明确说明原因。
- [ ] BUG清单记录实际问题、处理状态、修复后的复测结果和遗留影响；未发现BUG时注明测试范围及结果。
- [ ] 对照功能模块清单逐项核对运行截图，每个模块至少一张，并将截图放入总结报告DOCX。
- [ ] 能介绍主要源码位置及其作用，说明实际成员分工；逐人核对个人总结，不能用示例姓名代替真实成员。
- [ ] 源代码ZIP内容可解压、与验收版本对应，保留实际运行所需的项目配置和数据库脚本，排除本地口令、依赖缓存和构建输出。

测试最低范围按CR-09核对；最终系统演示按已确认的功能范围逐项检查。文档齐全、容器启动和业务测试分别登记，不能互相替代验证结论。
