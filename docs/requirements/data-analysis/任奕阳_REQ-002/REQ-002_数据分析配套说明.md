## 三、与REQ-003的分工

1. 拒收申请、拒收原因、拒收时间、拒收处理状态、撤回时间与撤回结果**全部由REQ-003维护**，本表只引用编号与状态，不复制其值，避免同一业务事实两处可改。
2. 本表保留“拒收核验信息”数据类，只表达工作人员核验结论（通过／驳回）与驳回原因。调研报告未规定驳回分支，该项以P002-04挂起，评审未通过前不得作为接口依据。
3. 包裹状态五个取值（待取件／已取件／拒收待退件／退件中／已退件）两模块共用，任何一方修改须同步另一方与共享登记。
4. 取件时间字段定义在本表（包裹主记录侧），写入动作由REQ-003完成，核验失败或未出库时不填。
