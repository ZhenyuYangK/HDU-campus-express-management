## 四、本轮确认的规则

1. **归属按账号ID建立**：包裹与账号的归属关系保存账号ID（学生为学号），手机号只作为入库与更正时的匹配依据。账号绑定手机号变更不改变既有归属，与[调研报告](../../research/校园快递收发系统调研分析报告.docx)第2.3节一致，不需要修改该节。
2. **更正手机号触发重匹配**：工作人员在FUNC-002-04更正某条包裹的收件手机号后，按新号码重新匹配；匹配到其他账号时转移归属，原归属账号写入更正前内容快照。已完成记录（已取件、已退件）只追加更正说明、不转移归属，依据调研报告第4.4节。
3. **不设人工拒收核验**：拒收有效性由系统在学生提交时自动校验（本人包裹、尚未取走、线上提交），退回分支不成立。P002-04据此关闭，REQ-002不设"拒收核验"功能项；退件办理前的"核对包裹与拒收原因"作为FUNC-002-03的办理前置，不产生独立结论字段。
4. **退件发起与循环**：学生拒收来源要求状态为`拒收待退件`且存在当前有效拒收申请；人工异常来源要求状态为`待取件`，含待关联包裹。交接未完成可多次办理，仍属同一条退件记录，避免期间退件完成量重复计数。
5. **退件原因组合**：来源为人工异常时禁止选择"学生拒收"；来源为学生拒收时默认"学生拒收"但允许按实际改选；原因为"其他"时说明必填。退回去向按现有两个取值填写，不新增第三取值。

## 七、验收要点

- **FUNC-002-01**：同一快递公司同一运单号重复提交不得形成两条有效入库记录；原记录已终态时可重新入库并带出原编号；匹配不到唯一账号时入库成功且学生端不可见；取件码站内唯一。
- **FUNC-002-02**：已关联包裹不能再次补关联；收件手机号与账号绑定手机号不一致时拒绝确认；补关联后该包裹立即对学生可见。
- **FUNC-002-03**：状态不符、拒收已撤回时不能开始退件；开始退件后学生不可撤回；完成登记不可重复，完成后不能恢复取件；人工异常来源不能选"学生拒收"。
- **FUNC-002-04**：已完成记录只出现"追加更正说明"；更正运单号命中未终态记录时不能保存；更正手机号后归属与快照同时体现。
- **FUNC-002-05**：管理员只能查看与导出，办理入口与后端请求均被拒绝；时间范围起止颠倒时拒绝查询；查询不改变任何记录。
