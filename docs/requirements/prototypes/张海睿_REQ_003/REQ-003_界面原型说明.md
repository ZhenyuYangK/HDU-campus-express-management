## 字段与输入约束

| 界面内容 | 数据项 | 展示或输入规则 |
| --- | --- | --- |
| 当前账号与包裹归属 | DATA-001-01 | 顶栏显示当前演示账号，保留前导零。查询和办理按已建立的账号归属控制。 |
| 快递公司、运单号、包裹状态、到站时间 | DATA-001-11、DATA-003-01、DATA-003-05、DATA-003-06 | 查询结果只读。运单号按文本展示。不同公司的同号运单分别显示。 |
| 存放位置、取件码与包裹定位 | DATA-001-12、DATA-003-04 | 待取件详情分开显示层位及取件码，组合显示如`C-2-A1B2C3`。原型按可取件条件控制定位区可见性。 |
| 取件码、收件手机号后四位 | DATA-003-04、DATA-003-07；系统核验依据包含DATA-003-03 | 两项必填，后四位按4位数字文本输入，保留前导零，输入时掩码显示。取件码仅检查非空并用于核验演示，长度、字符范围、重试和留存规则仍待评审。完整收件手机号及绑定手机号均不出现在本模块页面。 |
| 核验结果、取件时间 | DATA-003-08、DATA-003-09 | 通过后显示`取件完成`及时间。失败时就地提示；未出库时没有取件时间。 |
| 拒收对象、拒收原因 | DATA-002-01、DATA-003-11 | 系统按选中的入库记录定位。快递公司和运单号在对话框只读展示。原因按数据分析表的可空候选演示，必填性、字符数上限及空值映射待评审。 |
| 拒收申请编号、拒收时间、拒收处理状态 | DATA-003-10、DATA-003-12、DATA-003-13 | 由系统生成，学生只读。包裹状态与拒收处理状态分别显示。撤回后再次拒收使用新的申请编号和提交时间。 |
| 开始退件时间、退件完成时间、撤回时间、撤回结果 | DATA-002-34、DATA-002-35、DATA-003-14、DATA-003-15 | 退件时间取自对应事件，仅在事件发生后显示。撤回请求返回结果后展示撤回结果，成功时才展示撤回时间。 |

时间按UTC+08:00和`yyyy-MM-dd HH:mm:ss`展示。状态筛选是本地演示交互，服务端分页、排序、筛选参数、状态枚举和角色字段可见性依后续评审。姓名、地址等资料本次仅沿用REQ-001示例学生身份区，包裹详情不展示收件人姓名或地址。

## 场景与权限

- 默认进入学生端。导览的「查询加载中」「没有本人包裹」「查询请求失败」「无学生访问权限」可独立查看。权限不足时显示提示并隐藏业务导航和包裹数据。待关联、其他账号的包裹不会加入本人列表。管理员只读业务页面沿用所属模块设计。
- 正常取件示例为中通快递运单`001234567890`，取件码`A1B2C3`，收件手机号后四位`0003`。后四位填错、取件码填错、非本人或未关联、已取件、拒收暂停及退件中或完成时均无法出库。通过导览也可查看出库请求失败的反馈。
- 详情按入库记录区分包裹。对中通包裹提交拒收时，相同运单号的韵达包裹保持原状态。已存在有效拒收时隐藏提交入口，取消弹窗保留业务状态。导览可独立查看拒收请求失败。人工异常退件的包裹详情只显示退件状态与时间。
- 普通对话框支持取消、Escape及点击遮罩，关闭后焦点回到触发控件。提交中显示处理文案并禁用相关控件；成功后刷新详情或显示取件完成。导览用于切换独立样例，切换或重置会恢复合成数据。由REQ-002维护实际退件开始及完成事实，学生端按对应申请显示结果。

所有演示均在浏览器内使用合成数据。[OpenAPI](../../../api/openapi.yaml)的业务路径、operationId、字段Schema及错误码待TASK-003评审。实际权限拦截、后端归属校验、重复请求和事务处理须在应用中验证。

## 拒收与退件统一样例

学生端UI-003-06～10与任奕阳的[REQ-002退件样例](../任奕阳_REQ-002/REQ-002_界面原型说明.md#页面与功能对应)使用同一入库记录`RK20261121006`、拒收申请`JS20261121002`和京东快递运单`JD000444555666`。包裹位于`B-1`，到站时间为`2026-11-21 16:02:00`，拒收提交时间为`2026-11-21 18:20:00`。

| 路径 | 演示步骤 | 预期结果 |
| --- | --- | --- |
| 退件开始前撤回 | 在导览选择UI-003-06，填写拒收原因并提交，再点「撤回拒收」和「确认撤回」。也可从UI-003-08直接开始。 | 同一申请撤回成功，详情显示撤回时间`2026-11-22 09:39:00`，包裹恢复「待取件」及自助取件入口。 |
| 工作人员先开始退件 | 工作人员端在UI-002-07确认开始退件，导览的UI-002-06展示「退件中」状态。学生端选择「提交撤回时退件已开始」，再点「确认撤回」。 | 同一申请撤回失败，详情显示包裹及拒收处理状态「退件中」、开始退件时间`2026-11-22 09:40:00`。详情隐藏撤回时间、撤回入口和该包裹的自助取件入口。 |

两条路径分别从同一合成申请重放。学生端的失败场景模拟接收工作人员端的开始退件事实，两份原型独立运行。
