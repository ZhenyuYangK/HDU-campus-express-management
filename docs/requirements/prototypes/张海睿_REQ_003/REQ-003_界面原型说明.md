## 字段与输入约束

| 界面内容 | 数据项 | 展示或输入规则 |
| --- | --- | --- |
| 当前账号与包裹归属 | DATA-001-01 | 顶栏显示当前演示账号，保留前导零。查询和办理按已建立的账号归属控制。 |
| 快递公司、运单号、包裹状态、到站时间 | DATA-001-11、DATA-003-01、DATA-003-05、DATA-003-06 | 查询结果只读。运单号按文本展示。不同公司的同号运单分别显示。 |
| 存放位置、取件码与包裹定位 | DATA-001-12、DATA-003-04 | 待取件详情分开显示层位及取件码，组合显示如`C-2-A1B2C3`。原型按可取件条件控制定位区可见性。 |
| 取件码、收件手机号后四位 | DATA-003-04、DATA-003-07；系统核验依据包含DATA-003-03 | 两项必填，后四位按4位数字文本输入，保留前导零，输入时掩码显示。取件码仅检查非空并用于核验演示，长度、字符范围、重试和留存规则仍待评审。完整收件手机号及绑定手机号均不出现在本模块页面。 |
| 核验结果、取件时间 | DATA-003-08、DATA-003-09 | 通过后显示`取件完成`及时间。失败时就地提示；未出库时没有取件时间。 |
| 入库记录编号、拒收原因 | DATA-002-01、DATA-003-11 | 详情显示入库记录编号，系统按该编号定位包裹。快递公司和运单号在对话框只读展示。原因按数据分析表的可空候选演示，必填性、字符数上限及空值映射待评审。 |
| 拒收申请编号、拒收时间、拒收处理状态 | DATA-003-10、DATA-003-12、DATA-003-13 | 由系统生成，学生只读。包裹状态与拒收处理状态分别显示。撤回后再次拒收使用新的申请编号和提交时间。 |
| 退件记录编号、开始退件时间、退件完成时间、撤回时间、撤回结果 | DATA-002-02、DATA-002-34、DATA-002-35、DATA-003-14、DATA-003-15 | 退件编号与时间取自对应退件记录，与REQ-002工作人员端一致，仅在退件开始后显示。撤回请求返回结果后展示撤回结果，成功时才展示撤回时间。 |

时间按UTC+08:00和`yyyy-MM-dd HH:mm:ss`展示。状态筛选是本地演示交互，服务端分页、排序、筛选参数、状态枚举和角色字段可见性依后续评审。姓名、地址等资料本次仅沿用REQ-001示例学生身份区，包裹详情不展示收件人姓名或地址。

## 场景与权限

- 默认进入学生端。侧栏与REQ-001共用「我的包裹」「自助取件」「修改密码」，Logo返回「我的包裹」。导览的「查询加载中」「没有本人包裹」「查询请求失败」「无学生访问权限」可独立查看。权限不足时显示提示并隐藏业务导航和包裹数据。待关联、其他账号的包裹不会加入本人列表。管理员只读业务页面沿用所属模块设计。
- 正常取件示例为中通快递运单`001234567890`，取件码`A1B2C3`，收件手机号后四位`0003`。后四位填错、取件码填错、非本人或未关联、已取件、拒收暂停及退件中或完成时均无法出库。通过导览也可查看出库请求失败的反馈。
- 详情按入库记录区分包裹。对中通包裹提交拒收时，相同运单号的韵达包裹保持原状态。已存在有效拒收时隐藏提交入口，取消弹窗保留业务状态。导览可独立查看拒收请求失败。人工异常退件的包裹详情只显示退件状态与时间。
- 普通对话框支持取消、Escape及点击遮罩，关闭后焦点回到触发控件。提交中显示处理文案并禁用相关控件。拒收、撤回和出库按入库记录编号读取最新归属与业务状态。出库成功后写入首次取件时间；核验失败和重复办理保留原状态及时间。由REQ-002记录退件开始及完成事实，学生端按对应申请显示结果。
- 正常模式与课程导出从[共享初始业务数据](../shared/demo-data.js)生成包裹列表。正常模式还读取本标签页的演示变更。`IN-DEMO-OTHER`及未关联的最小核验样例只用于触发无办理权限提示，学生列表与详情仅使用业务记录。

所有演示均在浏览器内使用合成数据。[OpenAPI](../../../api/openapi.yaml)的业务路径、operationId、字段Schema及错误码待TASK-003评审。实际权限拦截、后端归属校验、重复请求和事务处理须在应用中验证。
